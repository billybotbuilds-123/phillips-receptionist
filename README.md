## Local Development

### Prerequisites

- Node.js 20+
- PostgreSQL 15 (local or Docker)
- npm

### Setup

```bash
# 1. Clone the repo
git clone https://github.com/<shane>/phillips-receptionist.git
cd phillips-receptionist

# 2. Install dependencies
npm install

# 3. Copy env template and fill in values
cp .env.example .env
# Edit .env — at minimum set DATABASE_URL

# 4. Run bootstrap (creates admin user + generates secrets)
npm run bootstrap
# Copy the printed env vars into .env

# 5. Generate Prisma client
npm run db:generate

# 6. Start web server
npm run dev

# 7. In another terminal, start the cron worker
npm run worker
```

The web server runs at http://localhost:3000  
Admin dashboard: http://localhost:3000/admin

### Environment Variables

See `.env.example` for the full list. The minimum for local dev:

```
DATABASE_URL=postgresql://user:pass@localhost:5432/phillips_receptionist
SETTINGS_MASTER_KEY=<64 hex chars — generated by npm run bootstrap>
SESSION_SECRET=<64 hex chars — generated by npm run bootstrap>
ADMIN_USERNAME=<your username>
ADMIN_PASSWORD_HASH=<bcrypt hash — generated by npm run bootstrap>
PORT=3000
NODE_ENV=development
PUBLIC_URL=http://localhost:3000
```

All API keys (Vapi, Anthropic, Twilio, ElevenLabs, etc.) are stored **encrypted in the database** and managed through the admin dashboard at `/admin/settings`. You do NOT need them to run locally.

## Project Structure

```
src/
  routes/
    vapi.ts           ← Vapi tool endpoints (called live during calls)
    calendly.ts       ← Calendly booking webhook
    admin/            ← Admin dashboard routes
    auth.ts           ← Login/logout/password reset
    health.ts         ← Railway health probe
  services/
    googleDocs.ts     ← Create/append Google Docs
    gmail.ts          ← Send email via Gmail API
    twilio.ts         ← Send SMS via Twilio
    calendly.ts       ← Calendly API client
    notifications.ts  ← Urgent alerts to Shane
  templates/
    emails/*.mjml     ← Email templates (compiled to .html at build)
    sms/*.txt         ← SMS templates (mustache)
    admin/*.ejs       ← Admin dashboard views
    googleDoc/        ← Google Doc template
  cron/
    followUp.ts       ← 15-min: send follow-up messages
    dailySummary.ts   ← 7am PT: summary email to Shane
    cleanup.ts        ← 3am: prune old sessions/tokens
  lib/
    settings.ts       ← Encrypted settings with 60s cache
    crypto.ts         ← AES-256-GCM encrypt/decrypt
    config.ts         ← Zod env var schema
    auth.ts           ← Session, bcrypt, rate limiting
    hmac.ts           ← Webhook signature verification
  index.ts            ← Fastify web server
  worker.ts           ← Cron worker (separate process)
```

## Key Rotation

To rotate a secret (e.g. Twilio auth token):

1. Generate new secret at the provider
2. Log into `/admin/settings`
3. Update the field → click Save
4. Click "Test connection" to verify
5. Revoke the old secret at the provider

For `SETTINGS_MASTER_KEY` rotation (more involved — see `DEPLOYMENT.md`).
